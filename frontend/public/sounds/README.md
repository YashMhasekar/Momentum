## File Requirements

- **Format**: MP3 (recommended for browser compatibility)
- **Quality**: 128-320 kbps recommended
- **Length**: 1-5 minutes (will loop automatically)
- **File Size**: Keep under 5MB per file for faster loading

## Troubleshooting

**Error: "Failed to load because no supported source was found"**
- Ensure audio files are in MP3 format
- Check file names match exactly (case-sensitive)
- Verify files are not corrupted
- Try re-downloading the audio files

**Audio doesn't play**
- Check browser console for errors
- Ensure browser allows audio playback
- Try clicking the sound card again (some browsers require user interaction)

## Notes

- Audio files are loaded on-demand (not preloaded)
- Files loop automatically when playing
- Only one sound plays at a time
- Audio stops when leaving the Focus Room page
